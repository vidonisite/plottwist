# PLOT TWIST

En React + Vite-prototyp för PLOT TWIST.

## Starta lokalt i Codespaces

```bash
npm install
npm run dev
```

Öppna porten som Codespaces visar. Välj gärna att göra porten synlig endast för dig medan du utvecklar.

## Bygg för publicering

```bash
npm run build
```

Den färdiga webbappen hamnar i `dist/`.

## Nuvarande status

- Hem, kamera och chatt är prototyper.
- Kameran startar först när användaren trycker på knappen.
- Chattmeddelanden är endast exempel och lagras inte i en databas.
- Appwrite Auth, Database, Storage och riktiga ansiktsdeformationer ska kopplas in senare.
- PWA-konfigurationen finns i Vite och behöver testas via HTTPS efter publicering.
